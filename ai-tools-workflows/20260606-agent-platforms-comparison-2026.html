类别分布

把“Agent”按实际使用入口拆开：写代码、做研究、连业务系统、做企业知识/流程。不要只看模型强弱，入口和权限边界往往更决定能否落地。

能力-成本矩阵

横轴是成本友好度，越右越便宜或更可控；纵轴是 Agent 深度，越高越接近能规划、调用工具、改文件或跑流程。

推荐结论

个人开发者 Cursor / Claude Code / Codex / Trae

需要高质量代码理解与多文件修改时选 Cursor、Claude Code 或 Codex；中国网络和中文生态优先时 Trae、通义灵码、Comate 更省心。

研发团队 GitHub Copilot / Cursor Teams / CodeBuddy / JetBrains AI

团队采购看权限、审计、代码隐私、IDE 兼容和账单可控性。已有 GitHub/Microsoft 体系时 Copilot 管理成本低。

业务自动化 n8n / Zapier / Make / Dify / Coze

轻量 SaaS 集成选 Zapier/Make；需要自托管、复杂逻辑和可控成本选 n8n；做知识库 Bot 和应用工作流选 Dify/Coze。

企业办公 Microsoft 365 Copilot / Google Workspace Gemini / Salesforce Agentforce

大企业优先考虑数据权限、合规、审计、现有软件栈和身份系统，而不是单点模型能力。

一句话选型：写代码看“仓库理解 + 多文件执行 + 测试闭环”；做运营看“连接器 + 权限 + 异常处理”；做企业看“数据边界 + 审计 + 成本上限”。
