阿赖耶识是 AI Agent 的记忆架构图吗？

一位 AI Agent 架构师在口播里说：一千五百年前，无著、世亲就画出了 AI Agent 的记忆架构图。读到“种子生现行、现行熏种子”时，他说：“这不是像，这就是我画了一年的 memory pipeline 闭环。”本页对照 CBETA 收录的原典和 Agent 记忆研究，逐条判断哪些说法成立、哪些说过头、哪些引文出处不准。

核对日期 2026-10-22 · 依据：用户提供的口播转写稿、《成唯识论》等原典、9 篇 Agent 记忆与模型训练论文

一句话结论：唯识可以当作设计 Agent 记忆的一面镜子，但它不是现成的架构图。

  • 可以借鉴三点。“种子生现行、现行熏种子”的循环、身份层、错误自我强化，这三点在 Agent 研究里都有呼应。
  • 不能直接照搬。口播在模型权重的倾向和外部记忆写回之间来回切换，都归到“阿赖耶识”，没有交代两者的差别。唯识也没有存储格式、索引、淘汰和权限的设计。
  • 三处引文要更正或标明。《大宝积经》原文是“假使经百劫”，不是“百千劫”；“万法唯识”是后世概括语，本次核对未在《成唯识论》《唯识三十论颂》中找到这一原句；“恒审思量、执以为我”是卷四和卷一两处的综合。

先定尺度：说“像”有三种强度

口播说“这不是像，这就是”。要判断这句话，先分清三种强度的“像”。强度越高，需要的证据越多。

口播能支持

功能相似

两个系统要解决的问题有相似之处。例如：都要解释“过去的经验怎样影响现在的反应”。

局部可以讨论

结构对应

两个系统的组成部分之间有相对稳定的映射。例如：前五识与输入通道。这一层只在个别环节成立。

推不出

理论同构

基本概念、因果关系和运行规则能系统地一一对应。口播说“这不是像，这就是”，需要的正是这一层，但口播没有给出证据。

阅读提示：八识与 Agent 模块的对照，是现代工程视角下的启发式类比，不是唯识学对计算机架构的预言，也不意味着两个系统在本体或因果机制上相同。

八识与 Agent 模块：逐层点开看

左边是口播的对应关系。点一层，右边显示唯识原义、口播说法、判定和更准确的说法。原文引自 CBETA 收录的玄奘译《成唯识论》和明代普泰《八识规矩补注》。

前五识 ↔ 多模态输入

唯识原义
依眼、耳等五根，分别认识色、声、香、味、触五境。《八识规矩补注》把它归为“非恒非审”：有间断，也不做审察思量。
四、非恒非審，謂前五識《八识规矩补注》卷二（T1865）
口播说法
前五识加第六识，大致类似模型的多模态输入加上当下的工作记忆。
判定
部分成立
更准确的说法
只到“功能相似”。前五识在唯识里不是单纯的数据接口，而是有特定所缘、所依和生起条件的认识活动。多模态编码器只在“分别接收不同感官通道”这一点上相似。

第六意识 ↔ 上下文推理

唯识原义
第六意识的活动不限于当前感官输入，也包括记忆、概念、分别和推理。《八识规矩补注》把它归为“审而非恒”：会审察思量，但有间断。
二、審而非恒，謂第六識《八识规矩补注》卷二（T1865）
口播说法
前五识加第六识，大致类似多模态输入加上当下的工作记忆。口播后文又说，会话结束时上下文清空。
判定
部分成立
更准确的说法
“有间断”与会话清空确实贴合。但上下文只是影响模型推理的条件之一，不能把第六意识等同于上下文。另外，卷一说“分别我执”要靠外来说法和后天分别才生起，而且只在第六意识中有：
分別我執亦由現在外緣力故，非與身俱，要待邪教及邪分別然後方起，故名分別，唯在第六意識中有。《成唯识论》卷一（T1585）
外加的人设 prompt 也是外部给定、可以替换的，所以本页认为它更像这一类，而不是末那识。这是本页的类比，不是论典原话。

第七末那识 ↔ 身份维持

唯识原义
这里说的是有染污的末那识；卷五说阿罗汉等位没有染污末那。它“恒、审思量”，缘第八识，执为实我，与我痴、我见、我慢、我爱四种烦恼恒常相应。《八识规矩补注》把它归为唯一“亦恒亦审”的识。
是識聖教別名末那，恒、審思量勝餘識故。《成唯识论》卷四（T1585）
一、常相續，在第七識，緣第八識，起自心相，執為實我《成唯识论》卷一（T1585），讲“俱生我执”的第一种
口播说法
“恒审思量、执以为我”，就是给 Agent 挂的专家人设和长期目标：手工实现一层持久身份。
判定
部分成立
更准确的说法
更准确的说法是“身份维持与自我归属功能的类比”。口播的八个字是综合说法：“恒审思量”见卷四，“执为实我”见卷一，不是一段连续原文。
末那的我执是“俱生”的，不靠外来教导，任运而起；prompt 人设可以随时替换，不满足“恒”。训练进权重的性格（Anthropic 2024 年起做的 character training）更接近“俱生”，但它不“审”。所以系统提示词里的角色设定，不能判定为末那识。

第八阿赖耶识 ↔ 记忆库

唯识原义
阿赖耶识含藏种子，是前七识生起的来源。种子不是一条条记录，而是“本识中功能差别”，即产生后续活动的潜在能力。
唯本識中功能差別具斯六義，成種非餘《成唯识论》卷二（T1585）
口播说法
仓库里存着无始以来的种子，就是记忆库。
判定
部分成立
更准确的说法
口播在两种机制之间来回切换，都归到“阿赖耶识”：训练形成的权重倾向（“权重的倾向一条都没走”）和外部记忆写回（“决策结果写回记忆库”）。两者的更新方式不同，见下一节的对照表。无论权重还是外部记忆，都不能仅凭“可更新”就等同于唯识的所熏机制。

“阿赖耶识”在 Agent 里被拆成了几块

口播把“记忆库”“权重里的倾向”都叫阿赖耶识。下表按实际的更新方式拆开，并标出每一项不应直接等同的唯识概念。

为什么不用“可熏性”给 Agent 部件打分。《成唯识论》卷二列出所熏四义：坚住性、无记性、可熏性、与能熏共和合性，并说“唯異熟識具此四義”。这是唯识关于熏习和因果连续性的理论条件，不是工程上“能不能写入”的定义。

一个常见推论是“推理时权重冻结，所以权重不满足可熏性”。这个推论不充分：权重在训练和微调时会更新；而外部记忆虽然能写入，也不因此满足全部所熏四义。所以权重与外部记忆都不能仅凭“可更新”就等同于唯识的所熏机制。

种子生现行、现行熏种子：能对应到什么程度

这是口播最核心的类比：检索、决策、写回的记忆闭环。下面的图可以逐步查看三个环节。

可以这样对应：外部记忆被检索并进入上下文，可作为“潜在条件影响当前活动”的类比；模型输出及其引发的行为，可作为“现行”的类比；输出被筛选、记录并写回记忆库，可作为“现行熏成新种子”的类比。三者不是严格的一一对应。
两处差别：第一，卷二说“三法展轉因果同時，如炷生焰、焰生焦炷”，这里的“三法”指能生的种子、生起的现行、新熏成的种子，是一种因果关系模型；新种子与旧种子之间是前后相续。Agent 是有先后顺序的程序步骤。差别在因果模型与程序执行模型，不只是快慢。第二，种子是“功能差别”，即潜在能力；外部记忆里存的是可读的文本记录。

会话清空后，什么会留下来？

口播引用“假使百千劫，所作业不亡”，说上下文清空看似归零，但模型权重的倾向一条都没走。这句话容易让人读出两个命题：第一，权重里既有的倾向还在；第二，那千百次会话里造下的“业”也留在了权重里。前者通常成立，后者在没有参数更新的普通推理过程中通常不成立。口播没有明说第二个命题，但“所作业不亡”的比喻容易让人这样理解。

会话上下文

当前对话窗口里的内容。新会话是否保留，取决于上下文管理；这不等于参数被更新。

本次错误：新会话里不保留

外部记忆

系统实际执行写入、保存，并在后续检索时取回，内容才会跨会话影响行为。

本次错误：没有写入，不会留下

模型参数

训练形成的既有倾向会持续影响输出。新会话中的内容不会自动进入权重。

既有倾向：仍在 · 本次错误：不会自动写入

后续训练

对话被收集进训练或微调数据后，才可能改变下一版模型的参数。

本次错误：没有进入训练，不影响下一版模型

本次会话的错误不会自动留到下一次会话；留下的是训练时已形成的既有倾向。

A7 判定：部分成立。成立的部分：清空会话上下文通常不会清除模型既有参数，所以预训练或微调形成的行为倾向仍可能影响后续输出。对不上的部分：“所作业不亡”说的是造下的业不消失，而权重里的倾向来自训练，不是那千百次会话造下的；本次会话的新信息和错误不会因为被模型生成就自动写入权重。只有存进外部记忆，或进入后续训练、微调，才可能跨会话影响。另外，《大宝积经》卷五十七的原文是“假使經百劫”。

“业力加速器”：错误怎样滚成雪球

口播说：向量库毫秒级检索，一个错误几小时就能在记忆库里滚成雪球。研究支持“错误会自我强化”这个方向；“几小时”是作者的个人经历，“几万倍”没有测量。下面的模型把两条反馈路径分开，看哪些条件会让雪球变大。

路径一：上下文内自我条件化。前面产生的错误进入后续上下文，影响下一步输出。Sinha 等（2025）观察到：上下文里含有模型自己先前的错误时，后续更容易出错；放大模型规模不能消除，thinking 可以缓解。会话一清空，这条路径就中断。
路径二：跨轮次持久化。错误被写入外部记忆，之后又被检索并用于新的判断。这才是“写回—再检索”构成的闭环。AgentPoison（2024）显示，投毒率低于 0.1% 时，平均攻击成功率高于 80%。

每一步的错误率 pₜ = min(0.95, p + k × 0.5 × e会话 + k × 0.5 × m)

e会话：本会话已走步骤的平均错误率，新会话从 0 开始。m：记忆池里的错误占比，只在“加记忆写回”线里起作用。假设每一步写回一条记录；正确记录全部写入，错误记录以 1 − g 的比例通过校验。所以 m = Σpₜ(1 − g) ÷ Σ[(1 − pₜ) + pₜ(1 − g)]。共 5 个会话，每个会话 20 步。

A11 判定：部分成立。方向有支撑；“几万倍”没有测量，“几小时”是作者的个人经历，没有给出可复核的记录。拿人的触发间隔（几年）和检索延迟（毫秒）相比，比较的是两个不同过程，不能据此算出加速倍数。在模型里，真正决定雪球大小的是写回—再检索的循环和写入校验，不是检索速度。

A1“一千五百年前”，印度兄弟无著、世亲在公元四五世纪创立唯识成立斯坦福哲学百科定世亲为 4–5 世纪，无著是他的兄长。“一千五百年前”是约数：世亲约 1600 年前；口播引用的论句出自玄奘 659 年糅译的《成唯识论》，约 1370 年前。
来源：SEP《Vasubandhu》
A2前五识加第六识 ≈ 多模态输入加工作记忆部分成立功能相似。前五识对应感官通道；第六意识“审而非恒”（不是持续不断）与会话清空贴合。但第六意识也包括记忆、概念和推理，不只是一个窗口。
来源：《八识规矩补注》卷二；《成唯识论》卷一
A3末那识“恒审思量、执以为我” ≈ 专家人设、持久身份部分成立“恒审思量”见卷四，“执为实我”见卷一，口播是两处综合。末那的我执是俱生、任运的；prompt 人设是外加、可替换的，更像卷一说的“分别我执”。
来源：《成唯识论》卷一、卷四
A4阿赖耶识 ≈ 记忆库部分成立口播在训练形成的权重倾向和外部记忆写回之间来回切换，都归到阿赖耶识，没有交代两者的差别。种子是“功能差别”，不是一条条记录。
来源：《成唯识论》卷二
A5种子生现行、现行熏种子 ≈ 检索、决策、写回的闭环；“这不是像，这就是”部分成立可以作流程示意，但不是一一对应。唯识讲“因果同时”，Agent 是串行步骤；检索本身也不一定是“种子生现行”。
来源：《成唯识论》卷二
A6《大宝积经》：“假使百千劫，所作业不亡，因缘会遇时，果报还自受”出处不准《大宝积经》卷五十七（义净译）原文是“假使經百劫，所作業不亡，因緣會遇時，果報還自受”。“百千劫”的写法在 CBETA 有 86 处，多见于后世语录、注疏和日诵集。
来源：《大宝积经》卷五十七；CBETA 全文检索
A7引“所作业不亡”：百千劫“是千百次的会话结束，上下文清空看起来一切归零，但模型权重的倾向一条都没走”部分成立成立的部分：权重里既有的倾向还在。对不上的部分：本页认为，“所作业不亡”的类比在经验写入机制上对不上。经文说的是造下的业不消失，而权重里的倾向来自训练，不是那千百次会话造下的；本次会话的错误不会自动写入权重。口播没有明确说会话错误会写入权重。只有存进外部记忆，或进入后续训练、微调，才可能跨会话影响。见“会话清空后”一节。
来源：本页分析
A8用 AI 生成的数据训练会越来越差，必须用干净的原始数据部分成立Shumailov 等（Nature 2024）：不加区分地用模型生成内容训练，会造成不可逆缺陷，原分布的尾部消失。Gerstgrasser 等（2024）：用合成数据替换真实数据会坍缩；把合成数据和原始真实数据累积在一起可以避免。所以重点是“保留真实数据”，不是“只能用原始数据”。
来源：Shumailov 2024；Gerstgrasser 2024
A9“我们花了几年造出来的 AI 机制，人却是出厂自带的”成立原话说的是机制：人不用配置记忆库，经历就会留下持久影响。这与唯识相符：卷二说种子除“本有”外，还有“始起”一类，由现行反复熏习而成，名为“习所成种”，而且“無始來”就是这样。口播举的项目翻车例子正属于这一类。这句话说的是机制自带，不是说种子本身都是天生的。
来源：《成唯识论》卷二
A10第七识被定义为根本无明；修行人看破它、转化它，穷尽一生想拆掉它说过头末那与我痴、我见、我慢、我爱四烦恼恒相应，卷五引经说“不共无明”。但识本身不等于无明：卷五说阿罗汉位断灭的是“染意種及現行”，“言彼無者，依染意說”；末那有三种，第三种与“平等性智”相应。口播说“看破它、转化它”，这一点与论典一致；“拆掉”可理解为修辞。需要纠正的是把第七识本身说成“被定义为根本无明”。
来源：《成唯识论》卷四、卷五、卷十
A11向量库毫秒级检索，是“业力加速器”；一个错误几小时就在记忆库里滚成雪球部分成立方向有支撑：自我条件化（Sinha 2025）、记忆投毒（AgentPoison、MINJA）。但“几万倍”没有测量；“几小时”是作者的个人经历，没有给出可复核的记录。拿触发间隔和检索延迟相比，比较的是两个不同过程，不能据此算出加速倍数。
来源：Sinha 2025；AgentPoison 2024；MINJA 2025
A12“唯识宗连业存在哪、怎么流转的数据库设计都给出来了”说过头唯识没有存储格式、索引、淘汰、权限的设计；种子是“功能差别”，不是可读的记录。现有 Agent 记忆设计来自操作系统分层内存（MemGPT）、认知科学（CoALA）等工程脉络。
来源：《成唯识论》卷二；MemGPT；CoALA
A13唯识宗有句总纲：“万法唯识”部分成立口播说它是“总纲”，没有说它出自哪部论典。作为后世概括语可以用，但不应当作早期唯识论典的原句。CBETA 检索“萬法唯識”共 408 条，本次核对未在《成唯识论》《唯识三十论颂》中找到，多见于《宗镜录》和后世禅宗语录。
来源：CBETA 全文检索
A14“原来我们从来不是在造机器，我们是在临摹自己的心”另有解释CoALA 明确说借鉴认知科学和符号 AI 的历史来设计 Agent 记忆模块；MemGPT 借鉴操作系统的分层内存。相似的一部分来自工程师有意参照人类认知模型，这不能证明心与 Agent 同构。
来源：CoALA；MemGPT

给 Agent 构建者的设计清单

口播最有用的部分，是作者自己说的“要设计反思机制，要防记忆污染，要判断什么值得存”。下面按证据强弱分三类。

有研究依据

  • 保留可追溯的真实数据来源，并评估真实与合成数据的比例、质量和用途。依据 Shumailov 2024、Gerstgrasser 2024。
  • 把记忆写入当作攻击面。少量投毒记录（AgentPoison）、普通查询（MINJA）都可能污染记忆库。写入权限和投毒检测是风险缓解措施，不是绝对防护，效果要自己测。

合理工程措施

  • 写入门控与新上下文复核。写回前，用不含原错误的新上下文复核关键结论。Sinha 2025 支持“错误会自我条件化”这个问题本身，但不能假定复核一定能发现错误。
  • 记忆溯源。记录来源、时间、置信度。置信度字段不等于事实为真。
  • 衰减与重要性加权。Generative Agents 结合相关性、近因（指数衰减）和重要性来检索。TTL、时间衰减和重要性加权各有取舍，不是所有任务都适用。

本页设计假设

  • 身份分层。训练得到的行为倾向，与运行时可修订、有版本的身份契约，分开管理。
  • 周期性评估与反馈环审计。定期抽查写回的记忆是否在放大错误。不按固定时间机械地清空全部记忆。
