03 / 四个付费产品，三个创始人组

案例验证的是特定机制和条件。收入都是历史自述。当前官网能证明商业报价存在，不能证明客户真的购买或当期利润。

历史创始人自述 · API 工作流

Bannerbear / Jon Yongfook

需求：创始人在电商工作中遇到每日手工制作图片的问题。早期 Open Graph 工具范围过窄，后来扩展为模板编辑器与 REST API。[S1]

结果：2020 年春 API 阶段约 $488 MRR；同年秋约 $6,109；2021 年初约 $10,455。均为本人报告。它是 API 服务提供方，并非简单 AI API 套壳的复现。

分发：教程、社群帮助、产品发布、用户反馈与功能改进并行；不是一次独立渠道实验。[S2]

反例：此前七个项目未有直接收入；推荐积分无效果，Shopify 版本失败。免费工具能获外链，也未必带来付费。[S1][S2][S3]

可迁移：重复营销 + 真实工作流改进。不可外推：复制目录产品、一两个月必成交。

创始人自述 · 直接访谈当前官网事实：无需订阅

HeadshotPro / Danny Postma

需求：将通用 AI 头像能力聚焦到职业形象照。2024-02-20 访谈中，创始人说 HeadshotPro 获得销售，而 Deep Agency 获得报道却未转化成销售。[S4]

05 / 把四步，补成能被证伪的闭环

0 · 找线索

目录、真实搜索结果、现有工作与用户抱怨 → 一条具体任务假设。收录与关键词难度只做线索。

1 · 明确付款方与任务

谁在什么情境做什么？多久发生一次？目前付钱或花时间给谁？第一批用户在哪里可触达？

2 · 拆 3–5 个直接竞品

记录承诺、结果示例、任务路径、价格与限制、获客入口、差评与缺口。Google 前排强度与购买意图分开看。

3 · 先提出有价格的交付承诺

用手工演示让目标用户评价具体输出。泛泛“不错”与点赞不算接受报价。

4 · 做最小贯穿路径

输入 → 可核验输出 → 付款 → 错误处理。通过工作流、质量、可信来源或集成增加价值。按任务频次选择单次、点数或订阅。

5 · 在相关渠道重复分发

复用筛选过的目录与合作清单，发布真实任务演示。记录渠道标签、有效访问与激活；不以链接数量做验收。

6 · 核对付费、验收和单位成本

付款确认、退款、完成任务、API 重试、免费使用、客服时间分别记录。看净贡献，而不只看账面收入。

7 · 看复用与续费，再决定扩大

订阅需要下一期实际账单与再次使用；一次性工具需要复购或持续的新客户来源。失败时回到任务与报价，不只加外链。

把竞品页面拆成一份开发清单

付款人 / 一句话承诺 / 输入样例 / 输出样例 / 三步路径 / 收费与限额 / 可信证据 / 错误与退款 / 数据处理与删除。模仿信息组织，不复制代码、图片或虚构客户评价。海外用户的“审美”应由目标用户的任务完成与理解来验收。

一个可测试的垂直假设：电商说明书问答

这是基于 PDF.ai 需求背景的研究者示例，不是已验证的新市场。输入一份商家有权使用的手册，输出答案、页码和“不足以回答”的提示。先请商家给真实售后问题，比较人工答复与工具结果。只有结果被接受、报价被接受、成本可覆盖，才继续开发。今天通用聊天工具已是替代方案，应测试具体工作流优势。

反证：目标用户认可输出，但不愿支付覆盖交付与获客成本的价格，机会仍失败。自然搜索和社媒曝光增长，不能推翻这个反证。

06 / 60 天只验证一个产品

以下是建议试验，不是经验保证。示例上限：$300 现金、40 小时、一个产品。此上限对应整个 60 天；下方计算器是可单独调整的一个观察窗口，不自动等于整段实验。开始前按实际资源调整。本文未代你招募、联系客户、发外链或购买任何服务。

第 1–7 天 / 任务与人

访谈 5 位目标用户，整理 10 条具体任务或抱怨，比较 3 个付费替代品。没有可触达付款方，暂停或换任务。

第 8–14 天 / 报价与演示

向 3 位目标用户演示最小结果。明确价格、交付标准与失败处理。记录拒绝理由，不以“有兴趣”充当成交。

第 29–60 天 / 重复与归因

一个主渠道、一个对照渠道。每周两次任务演示，筛选五个相关目录或合作机会。每周按访问、激活、付费和验收调整。

建议：继续下一轮的门槛

至少 3 位独立付费客户、至少 2 次被接受的交付、单位净贡献为正。它们只是学习门槛，不是统计证明，也不直接授权扩大投放。

调整或停止的建议门槛

订阅后续账单与续费观察可能跨过第 60 天。首单、续费和盈利不能合并成一个验收结果。

07 / 少流量能有首单，也能亏钱

期望首购人数1.00
至少一单概率（独立同率假设）63.3%
期望净保留收入$17.15
期望全部激活成本$10.00
期望现金结果-$42.85
期望扣时结果-$192.85

公式、假设与漏项

期望首购人数 N = V × a × b。净保留收入 R = N × P × (1−r) × (1−f)。全部激活成本 = V × a × C，包含未付费用户。现金结果 = R − 激活成本 − A − F；扣时间后的结果 = 现金结果 − H × W。

至少一单概率 = 1 − (1−a×b)V。该式假设每位访问者独立、购买概率相同；现实流量不一定满足。首购人数按退款前付款计，不代表净留存客户。零成交时，在默认激活成本假设下，现金结果为 −$60。默认期望 1 位付款人，至少一单概率仍只有约 63.3%，不保证成交。

费率 f 用净保留收入上的有效成本近似，未单独建模每单固定费用和不可退手续费。按实际账单折入 C、f、A 或 F；C 应计入重试、免费调用与交付返工。不预测续费、流失率或 LTV。
