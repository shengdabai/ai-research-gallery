例证／反证：AWS SLA 明确了多可用区等条件；拥有 GPU 只是其中一个投入条件。

例证／反证：可验证的是人才入职后重复达到同一能力所需的时间与成本，而不是“能跳槽所以无壁垒”。

03 / VALUE CAPTURE

供给稀缺和长期壁垒是两件事。

基础设施芯片、内存、互联、供电与调度
观察：每瓦吞吐、有效利用率、交付周期
模型能力困难任务成功率与能力领先
观察：同预算任务胜率、领先持续时间
工作流与入口数据、工具、身份和分发
观察：接入成本、切换成本、委派频率
成功交付验收、审查与异常恢复
观察：合格结果、恢复能力、人工成本
价值回收被客户接受的结果与持续付费
观察：成功任务成本、净收益、续费

贯穿各层的是分发与客户关系、合同与切换成本、资本与迭代反馈。这张图是概念链条，不表示收入占比。每层都可能发生价格竞争，也可能形成不同的壁垒。客户购买的是合格结果：模型更聪明却无法拿到上下文，或算力更便宜却交付慢，都可能失去订单。

价值捕获的反例

75.0%

NVIDIA FY2026 Q4 公司 GAAP 毛利率，季度截至 2026-01-25。该季度收入为 681 亿美元。

[NVIDIA：FY2026 第四季度财报]

只能说明当时仍有高毛利。不能单独识别其中多少来自短缺、技术、生态或产品组合，也不能证明未来不会下降。

“有卡就有云”的缺口：AWS 的服务条款对跨可用区部署、可用性与服务抵扣设定条件。企业云交付还需要运行与恢复能力。硬件存量只是输入。[AWS：Compute SLA]

“差芯片也能用”的边界：弱芯片可能满足低频、离线、低延迟要求不高的任务。大规模同步训练和实时多步代理还受内存、网络与串行步骤限制。MTIA 300 的通信软件／硬件协同设计是具体例证；它针对推荐训练，不能外推为通用 LLM 集群的等价替代。[Meta：MTIA 300 网络与软件协同设计]

iPhone／小米类比只能帮助提出“功能接近不代表利润相同”的问题。要迁移到模型 API，必须进一步证明品牌、用户习惯、性能差异与切换成本；不能借手机行业的结论直接证明前沿模型永久定价权。
04 / CODING AS AN EXECUTION INTERFACE

Anthropic 的路径：能力、分发与产品相互强化。

2024-06｜Claude 3.5 Sonnet

发布时已有聊天、API 与云渠道，也提供代码编辑与执行能力。它并非只做 Coding 的单一垂直模型。[Claude 3.5 Sonnet 发布]

2024-10｜进入 GitHub Copilot

第三方编码入口开始提供 Claude 模型。这个时间点支持“分发合作扩大可触达任务”的假说；没有提供合作的收入因果拆分。[Claude 加入 GitHub Copilot]

2025-05｜Claude Code 面向公众

模型公司进入自有开发工作流产品。路径从向工具供模型，扩展到直接提供代理体验。[Anthropic：Series G 与 Claude Code 经营口径]

2026-02｜出现收入信号

公司自报 Claude Code 年化运行收入超过 25 亿美元，企业客户贡献超过其收入的一半；公司整体年化运行收入为 140 亿美元。[Anthropic：Series G 与 Claude Code 经营口径]

年化是当时收入速度的外推；不是已实现全年收入，更不是利润。没有订阅与 API 利润拆分。

Coding 的泛化来自哪里

代码能描述规则、连接系统、处理数据，并且经常可以运行和测试。智能输出因而更容易变成可检查的执行过程。

但测试通过只覆盖写明的要求。客户需要的业务结果、数据正确性和边界条件仍要另行验收。

它不是唯一泛化路径

Deep research 将搜索、阅读、数据分析组合成多步骤研究产品。它和 Coding 可以重叠，而不是互相排斥。

[OpenAI：Introducing deep research]

本次没有拿到搜索、视频、多模态的可比利润，因此无法判定这些方向“都失败”。

反证约束：METR 的 2025 随机试验中，16 名熟悉自身开源仓库的开发者完成 246 项任务，允许使用当时 AI 工具的任务耗时长 19%。这提示审查与返工可能抵消生成速度；不能外推为所有开发者或 2026 工具都变慢。[METR：早期 2025 AI 开发者随机试验] 后续试验存在参与选择与计时偏差，研究者没有把它当作可靠的当前提速估计。[METR：调整后续试验设计]

优化后的因果假说：能力改善 → 更多编码工作流采用 → 更丰富的任务反馈与产品经验 → 继续改进能力与工作流。这里的箭头仍需内部实验支持。融资、企业渠道、可靠性和执行工具也可能是共同原因。

05 / ORGANIZATION & COOPETITION

组织一致性有价值，但不能代替资源与验证。

视频把现金流判断改为文化判断，值得保留为一个假说。问题是，两者没有被严格隔离。使命集中可能减少协调；生存压力也可能造成短期承诺、超额支出与失去研究耐心。旧公司既有包袱，也有客户、基础设施和分发。

分析框架：不同优势与相应反证，不是公司排名
路径可能优势可能代价怎样验证
新 AI 公司目标集中、研究与产品一致融资与供给依赖、能力路线押注资源决策周期、交付成功率、现金消耗
既有巨头现金流、终端、渠道与客户部门协调、既有业务取舍AI 产品复用、任务成本、独立团队授权
跨层合作云订单、供给分散、股权收益机会竞争者能力增强、商业依赖合同收入、投入回报、替代供给、冲突处置

Google 自报 Gemini 超过十亿月活，是巨头参与新周期的产品规模反例。它不证明前沿技术领先，也不能直接与 ChatGPT 的周活比较。[Google：Gemini 超过十亿月活]

金额核验：据 2026-04-24 报道，Google 投资结构为 100 亿美元当期承诺加 300 亿美元有条件投入，上限 400 亿美元。[Google 投资 Anthropic 条件结构]

竞争者同时可能是云客户。Anthropic 公布了 Google TPU 使用扩张计划，并采用多平台算力。投资与云合作因此可兼容竞争；这些事实不能证明 Google 的内心动机，也不能证明 Gemini 团队士气或跳槽因果。[Anthropic：扩大 Google TPU 使用]

创始人身份的事实修正：NVIDIA 官方介绍显示 Jensen Huang 是创始人、总裁与 CEO。因此“七巨头只有 Meta 由创始人管理”不成立。[NVIDIA：Jensen Huang 官方介绍] 创始人身份既不保证正确决策，也不能单独衡量创新耐心。

06 / PERSONAL AGENT

补充例证：单步好用，不等于整链可靠

现实中的状态恢复、人工确认和重试会改变这条链。只演示一次成功，无法识别这些成本；代理应报告最终任务验收率。

市场更大的必要条件：把“覆盖更多人”拆成任务发生频率 × 可授权比例 × 可靠完成率 × 支付或交易收入。范围扩大可能带来更多隐私边界与例外处理，并不自动提高可服务市场。

建议的四周小试验：只验证一个重复任务

这是研究建议，不是已经执行的客户实验；下述数值是可调整的试验门槛，不是行业基准。

第 1 周｜建立基线

邀请 5 名目标使用者；每人选择一个真实重复任务。记录原耗时、错误、频率与愿意授权范围。冻结什么叫合格结果。

第 2 周｜人审试运行

以只读或草稿模式完成任务。建议总样本不少于 30 项；记录推理、重试、确认、返工和异常。样本太少则延长观察。

第 3 周｜看自然复用

建议至少 3 人在没有额外提醒下每周复用两次。按合格结果计数。区分任务没发生、工具不会用和结果不可信。

第 4 周｜看支付与停止条件

建议至少 1 人实际购买可验收的小服务；总人工时间较基线减少 30% 作为继续门槛。未达到则改任务或停止。任何未授权发送／购买立即停止相关执行。

这里验证的是一个窄工作流。即便全部达到，也不能外推成全球市场、通用代理留存或 Meta／Instinct 的业务表现。反之，一次失败也不否定整个方向。

10 / OPTIMIZED ARGUMENT

可以替换原视频主论证的一段话。

AI 行业可能同时发生两件事：同等能力越来越便宜，而最困难任务仍愿意购买更可靠的智能。硬件与云的短缺溢价可能下降，但系统工程、规模运行和客户迁移成本不因此消失。前沿模型的商业优势也不是永久保证；它要把能力领先变成客户接受的结果，并在总成本上保持吸引力。

Anthropic 的 Coding 路径值得关注，因为代码把模型输出接入工具、数据和自动化，而且更容易运行和检查。其产品与年化收入信号支持这一方向的重要性；现有公开材料还不能把成功完全归因于专注文化，也不能由分发顺序证明第三方产品的贡献大小，也不能证明其他垂类都不赚钱。

Personal Agent 可能扩大委派任务的人群，但更广的人群不等于更大的实际收入。榜单、广告和估值只说明分发与资本关注。下一步应检查用户是否反复委派、结果是否可靠、授权是否可控、服务成本是否由支付或交易收入覆盖。Meta、Google 与创业公司都有可能在某些层次获胜；目前不足以给出必然胜者。

这是基于本次核验的分析性重写。没有将匿名博主的主观体验升级为事实。
