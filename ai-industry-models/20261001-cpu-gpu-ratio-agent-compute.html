论断核验:视频里的 10 句话

判定只针对「说法与公开证据是否一致」。「查无出处」不等于嘉宾没说过,只表示无法由公开材料印证。

视频说法判定证据与说明
Anthropic 的人预测 2028 年 CPU:GPU 走到 1:1查无出处 中英文检索均未找到该分享的公开记录。Anthropic 的公开表态只有算力负责人 James Bradbury 称 Vera 是「解决 agentic 工作负载的有前景的一环」,没有给比例。[1]「2028」这个时间点也没有对应的公开预测;AMD 的说法是「未来 3–5 年优于 1:1」。[6]
这个信息国内都没人讨论不成立 TrendForce 2026-04-14 已发专题;知乎、虎嗅、微博、券商研报自 4 月起密集讨论,中信证券甚至提出极端情形 8:1。[9][28]
过去 CPU 和 GPU 大概是 1:8基本成立 Intel CFO:训练场景约 7–8 颗 GPU 配 1 颗 CPU;TrendForce:现有 AI 数据中心约 1:4 到 1:8。[4][9]
这是「总算力比」口径错误 行业讲的是芯片颗数(或插槽数)之比,不是算力之比。算力无法这样直接比较。
现在正从 1:8 往 1:4 走成立 Intel CEO 陈立武 2026-04-23:「过去是 1 比 8,现在是 1 比 4,正走向对等甚至更高。」[4]
英伟达推出 Vera,官网写着 CPU for Agents成立 2026-05-31 新闻稿标题即《NVIDIA Unveils Vera, the CPU for Agents》。[1]
过去 99% 是矩阵相乘,CPU 只负责开机调度修辞夸张 方向对(CPU 曾主要做 host 节点),但「99%」没有数据来源。
Agent 的工具调用、跑代码、沙箱大量发生在 CPU 侧成立 两项独立实测支持:工具处理最高占端到端延迟 90.6%;Azure 生产流量中超过 27% 的请求工具耗时不低于模型推理。[10][11]
AI 上游的钱将不再高度集中在 GPU证据不支持 CPU 增速很快,但基数小。金额比今天约 1:6–1:8,2030 年最乐观预测仍约 1:7,见「钱往哪走」。
中国产业积累恰好踩中风口部分成立 光模块确实全球领先;服务器 CPU 有完整梯队但体量小,且先进制程瓶颈与 GPU 相同;海外 CPU 出口管制较松,反而能进入中国市场竞争,见「中国产业链」。

读法:机理成立——Agent 让 CPU 上了关键路径。但两项研究量的是「一个请求的时间怎么分」,不是「机房里该放多少颗 CPU」。负载是低均值加高尖峰:按均值配会在尖峰卡住 GPU,按尖峰配又大量闲置。这正是 1:1 至今缺少实验依据的原因。

钱往哪走:颗数 1:1 不等于金额 1:1

  • Intel 称 Xeon 供不应求,未满足需求「以 B 开头」(十亿美元级);预计全行业供给紧张持续到明年。[26][5]

  • 有报道称 AMD EPYC Venice 2027 年产能已售罄(单一来源,待证实)。[27]

  • 摩根士丹利认同瓶颈正移向 CPU 与内存,但不建议直接买 CPU 股,更偏好 NVIDIA、博通与存储,理由是 CPU 公司估值已高(23–64 倍市盈率)。[14]

被视频忽略的三个反向因素

  • CPU 管制更松,对国产是双刃剑。服务器 CPU 的出口限制比先进 GPU 轻。路透社报道 NVIDIA 已向中国客户推销 Vera,阿里与字节跳动在官方合作名单中。[23][1]GPU 买不到,国产替代是刚需;CPU 买得到,国产就要正面拼性能与生态。
  • 规则仍在收紧。美国商务部 2026-05-31 指引重申:向总部在中国的实体(含其海外子公司)出口先进计算产品须申请许可。[24]后续是否延伸到高端 CPU 是未知数。
  • 制程不分 CPU、GPU。Agent 需要的是高核数、高内存带宽的先进 CPU,同样依赖先进制程与先进封装。瓶颈「分散」到 CPU,并没有绕开制造这一关。[22]

判断:「中国踩中风口」对光模块等环节成立,对服务器 CPU 只能说「有牌可打」。更稳妥的说法是:Agent 让国内信创 CPU 多了一个增量场景(海光、鲲鹏的增速已经体现),但全球 CPU 增量的大头,目前流向 AMD、Intel、NVIDIA、Arm 与云厂商自研。

反方与不确定性

质疑 1:1 的理由

  • 没有任何已发表研究改变过 CPU:GPU 配比做对照实验;两项实测都在固定配置上测「时间怎么分」。[12]
  • CPU 平均利用率低、尖峰高,可通过调度、超卖、核池化提高利用率,而不必堆硬件。Azure 论文的原型系统正是这么做的。[11]
  • NVIDIA「比 x86 快 1.8 倍」的 agentic 基准被独立分析指出是 4 项常规整数测试,整机差距约 3%。[12]
  • 按功耗而非颗数来衡量可能更合理;AMD 自己的机架分析就是按 100kW 归一。[12]

可能让趋势落空的变量

  • Agent 落地不及预期:德勤调查显示仅 11% 的组织已在生产中使用 AI agent,38% 在试点。[30]
  • 云厂商资本开支放缓,或 agent 工具执行被搬到端侧与用户本机。
  • 旧服务器 CPU 足以承担大量工具负载,新增需求被存量吸收。[12]
  • Intel 18A 良率与 TSMC 先进产能分配决定供给能否跟上。[9]

基准约 1:1编码与通用 agent 成为主流负载,头部实验室继续签 CPU 长约约每 7 个 GPU 机架配 1 个 CPU 机架
激进CPU 多于 GPU多智能体与强化学习环境大规模并行CPU 机架与 GPU 机架 1 比 3 以内

倾向性判断:以 Anthropic、OpenAI 这类 agent 流量最重的买方为样本,2028 年颗数接近 1:1 是可信的;推广到「全行业 AI 服务器」则偏乐观。无论哪种情景,金额重心仍在加速器。

值得持续跟踪的指标

  • Intel DCAI 与 AMD 服务器 CPU 的季度增速能否维持在 50% 以上。
  • NVIDIA 是否单独披露 Vera 收入(200 亿美元目标的口径各家报道不一)。[29]
  • 是否有云厂商或实验室公布实际的 CPU 机架配比。
  • 海光、鲲鹏的营收增速与国产先进制程产能。
  • 美国对高端服务器 CPU 的出口规则是否变化。

这份结论怎么用

  • 看投资叙事:把「比例」换成「金额」再判断;趋势成立不等于相关公司估值便宜。
  • 看职业方向:CPU 侧的增量其实是软件问题——沙箱、编排、调度、权限、检索,这些 agent 基础设施能力的需求是确定的。
  • 看信息源:「硅谷一手消息」先问三件事:原话在哪、谁在卖什么、数字是哪种口径。
